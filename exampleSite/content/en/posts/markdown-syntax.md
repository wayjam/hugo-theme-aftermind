## Headings & Measure

For comfortable long-form reading, line width is constrained around `66ch`. Latin text uses self-hosted IBM Plex Serif with generous line height so human prose remains the visual anchor.

### Theme Shortcodes: Margin Notes & Redactions

Aftermind ships two shortcodes tailored to archival notebooks:

1. **Margin Note (`note`)**: Floats to the right rail on wide screens with bidirectional reference highlighting, and toggles inline on narrow viewports.{{< note >}}This note is generated by the `note` shortcode. When JavaScript is unavailable, it degrades cleanly inline so no context is lost.{{< /note >}}
2. **Redaction (`redact`)**: Preserves the struck-through phrasing beside the revision. For example, classifying this record as {{< redact "pending work" "an unread echo" >}}.

## Tables & Footnotes

Structured comparisons use restrained hairline borders and scroll horizontally on narrow viewports[^1]:

| Module | Default | Configuration |
| --- | --- | --- |
| Pagination | 5 entries per page | `[pagination] pagerSize` |
| Search | `json` index | `[params.search] provider` |
| Math | Disabled per post | Front Matter `math = true` |
| Diagrams | Disabled per post | Front Matter `diagrams = true` |
| Comments | Disabled | `[params.comments] enabled = true` |

Together these primitives form Aftermind's everyday writing baseline.
