本文用于展示 **Aftermind** 的基础排版规范与主题专属短代码。文章包含多个二级与三级标题，用于触发桌面端左轨目录与移动端折叠目录。

## 标题与段落节奏

在长时间阅读中，行长被限制在约 `66ch` 以内。中文与拉丁字母混排时保持克制的字距与行高，让正文成为画面的绝对主角。

这是一段包含**粗体强调**、*斜体语气*、~~删除线~~、`行内代码` 与 [外部链接](https://gohugo.io/) 的示例文字。

### 主题短代码：旁注与涂改

Aftermind 提供两种贴合档案手记气质的短代码：

1. **旁注（`note`）**：宽屏下在右侧边栏与正文编号双向联动，窄屏下点击编号原地展开。{{< note >}}这条旁注由 `note` 短代码生成。在无 JS 环境下会自动降级为行内显示，不影响阅读完整性。{{< /note >}}
2. **涂改留痕（`redact`）**：保留被划去的旧措辞，并在紧邻处标出更正后的词句。例如：把这份记录归类为{{< redact "待办事项" "无人翻阅的余响" >}}。

## 表格与脚注

当数据需要并置对照时，表格采用极简横线分隔，窄屏下自动允许横向滚动[^1]：

| 模块 | 默认状态 | 配置方式 |
| --- | --- | --- |
| 归档分页 | 示例站每页 5 篇 | `[pagination] pagerSize` |
| 站内搜索 | `json` 轻量索引 | `[params.search] provider` |
| 数学公式 | 按篇关闭 | Front Matter `math = true` |
| 图表渲染 | 按篇关闭 | Front Matter `diagrams = true` |
| 评论系统 | 默认关闭 | `[params.comments] enabled = true` |

---

以上元素共同构成 Aftermind 的日常写作基线。

[^1]: 脚注由 Goldmark 原生生成，文末自动附带返回锚点。
